Ενημέρωση σε νέα έκδοση

Κάθε φορά που θέλετε στο staging ό,τι έχει ο κλάδος main. Η σειρά μετράει: πρώτα κώδικας και εξαρτήσεις, μετά build, μετά βάση, και τελευταία επανεκκίνηση του worker.

Οι εντολές

cd /home/kaikistg/kaiki

php8.4 artisan down --retry=60                      # προαιρετικό — δείτε παρακάτω

git fetch origin
git checkout main
git pull --ff-only

php8.4 $(command -v composer) install --no-dev --optimize-autoloader

export PUPPETEER_SKIP_DOWNLOAD=1
npm ci
npm run build
npm run widget:build
php8.4 artisan widget:publish

php8.4 artisan migrate --force

php8.4 artisan config:cache
php8.4 artisan route:cache
php8.4 artisan view:cache

php8.4 artisan queue:restart                        # ο Supervisor τους ξεκινά με τον νέο κώδικα

php8.4 artisan up
git pull --ff-only Αρνείται αν κάποιος άλλαξε αρχεία στον server. Στον server δεν αλλάζει τίποτα με το χέρι εκτός από το .env, που δεν είναι στο git.
widget:publish Κάθε φορά, ακόμη κι αν δεν αλλάξατε το widget: το public/widget δεν έρχεται με το git. Η έκδοση διαβάζεται από το packages/widget/package.json· αν δεν ανέβηκε, το ίδιο vX.Y.Z απλώς αντικαθίσταται. Το alias /widget/kaiki-widget.js κρατιέται πέντε λεπτά σε cache στους browsers.
config:cache … Γράφουν πάνω από τα παλιά, άρα δεν χρειάζεται clear πρώτα. Μην τρέξετε optimize:clear στα τυφλά: αδειάζει και το Redis cache, με τα κλειδώματα και τα Idempotency-Key.
queue:restart Οι workers έχουν φορτώσει τον παλιό κώδικα στη μνήμη. Αυτό τους λέει να τελειώσουν την τρέχουσα εργασία και να βγουν· ο Supervisor τους ξανανοίγει.
down / up Για ενημέρωση με migration που αλλάζει πίνακες. Όσο είναι κάτω, και τα webhooks της Viva παίρνουν 503 — η Viva ξαναπροσπαθεί, και το payments:reconcile μαζεύει ό,τι έμεινε. Για μικρές αλλαγές παραλείψτε το.
Αν αλλάξατε μόνο το .env

config:cache, route:cache και queue:restart. Τίποτε άλλο.

Αν μια migration αποτύχει

Η εφαρμογή μένει στη μέση: νέος κώδικας, παλιό σχήμα. Διαβάστε το σφάλμα, διορθώστε στον κώδικα, και ξανά από την αρχή. Στο staging, αν τα δεδομένα δεν σας νοιάζουν, php8.4 artisan migrate:fresh --seed --force ξεκινά από το μηδέν — με όσα λέει το μέρος Γ για το email και τους κωδικούς.
