Μέρος Ζ

Σύνδεση του WordPress

Το aegeancr.gr παίρνει το πρόσθετο Kaiki Booking και ένα δημόσιο κλειδί, και δείχνει στο kaiki.testing.gr αντί για το Kaiki της παραγωγής. Ο αναλυτικός οδηγός του προσθέτου είναι ο «Οδηγός WordPress»· εδώ μόνο ό,τι αλλάζει για το staging.

Το αρχείο του προσθέτου

Το πρόσθετο δεν έχει εκδοθεί ακόμη, οπότε το zip το φτιάχνετε από το αποθετήριο. Δεν έχει εξαρτήσεις στην εκτέλεση — θέλει μόνο το autoloader του Composer, που δεν είναι στο git (packages/wordpress-plugin/kaiki-booking/vendor στο .gitignore). Φτιάχνετε ένα αντίγραφο, βάζετε autoloader χωρίς τα εργαλεία ανάπτυξης, και αφαιρείτε ό,τι είναι για δοκιμές. 

Σε Linux ή Git Bash, από τον φάκελο του αποθετηρίουrm -rf /tmp/kaiki-plugin && mkdir -p /tmp/kaiki-plugin
cp -r packages/wordpress-plugin/kaiki-booking /tmp/kaiki-plugin/
cd /tmp/kaiki-plugin/kaiki-booking

rm -rf vendor .phpunit.cache
composer install --no-dev --optimize-autoloader --no-interaction
rm -rf tests phpunit.xml phpcs.xml composer.lock .phpunit.cache

cd .. && zip -r kaiki-booking.zip kaiki-booking -x '*.DS_Store'
Σε PowerShell (Windows)$src = "C:\Users\Mike\kaiki\packages\wordpress-plugin\kaiki-booking"
$tmp = Join-Path $env:TEMP "kaiki-plugin"
Remove-Item $tmp -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory $tmp | Out-Null
Copy-Item $src $tmp -Recurse
Set-Location "$tmp\kaiki-booking"
Remove-Item vendor, .phpunit.cache -Recurse -Force -ErrorAction SilentlyContinue
composer install --no-dev --optimize-autoloader --no-interaction
Remove-Item tests, phpunit.xml, phpcs.xml, composer.lock -Recurse -Force
Set-Location $tmp
Compress-Archive -Path kaiki-booking -DestinationPath "$env:USERPROFILE\Desktop\kaiki-booking.zip" -Force

Μέσα στο zip πρέπει να υπάρχει ένας φάκελος kaiki-booking/ με kaiki-booking.php, vendor/autoload.php, src/, assets/, templates/, languages/ (με τα .mo και .json των ελληνικών, που είναι στο git), readme.txt και uninstall.php. Χωρίς vendor/autoload.php το πρόσθετο δεν σκάει — δείχνει ειδοποίηση στο διαχειριστικό ότι λείπει. Το πρόσθετο θέλει WordPress 6.4+ και PHP 8.1+ στη φιλοξενία του aegeancr.gr.

Δεν υπάρχει επίσημο script build

Το αποθετήριο δεν έχει .distignore ούτε εντολή που να φτιάχνει το zip. Η λίστα αφαιρέσεων παραπάνω βγαίνει από το τι υπάρχει στον φάκελο: ό,τι είναι για phpunit και phpcs. Αν αργότερα προστεθεί επίσημο build, ισχύει εκείνο.

Στο https://kaiki.testing.gr/app, ως ιδιοκτήτης του διοργανωτή: Ρυθμίσεις → Κλειδιά API → Νέο κλειδί API.

Επιτρεπόμενοι ιστότοποι https://aegeancr.gr και, αν ανοίγει και με www, https://www.aegeancr.gr. Ακριβώς έτσι: με https://, χωρίς / στο τέλος. Από εδώ βγαίνει και το «← Επιστροφή στην ιστοσελίδα».

Για τις σελίδες εκδρομών του WordPress (προαιρετικό) χρειάζεται και δεύτερο κλειδί: τύπος Μυστικό (sk_…), περιβάλλον δοκιμαστικό. Εμφανίζεται μία φορά· μπαίνει μόνο στο πεδίο «Μυστικό κλειδί» της καρτέλας Σελίδες εκδρομών, και ποτέ σε σελίδα.

Οι ρυθμίσεις στο WordPress

  1. Πρόσθετα → Προσθήκη νέου → Αποστολή προσθέτου, το kaiki-booking.zip, Ενεργοποίηση.
  2. Ρυθμίσεις → Kaiki Booking → Σύνδεση. Στο «Διεύθυνση του Kaiki» γράψτε https://kaiki.testing.gr — η προεπιλογή είναι το Kaiki της παραγωγής. Το πρόσθετο παίρνει από εδώ και το widget (/widget/kaiki-widget.js) και το API.
  3. Στο «Δημόσιο κλειδί» το pk_test_…. Αποθήκευση αλλαγών, μετά Νέος έλεγχος: πρέπει να γράψει «Συνδεδεμένο» και τον αριθμό «Ορατές εκδρομές».
  4. Προαιρετικά, Σελίδες εκδρομών: διακόπτης, το sk_…, αποθήκευση. Το «Τελευταία ενημέρωση» δείχνει αν πέτυχε ο συγχρονισμός.
  5. Μια σελίδα με [kaiki_booking product="…"], [kaiki_list] ή [kaiki_enquiry] — ή το block ή το widget του Elementor.
«Άμεσες ενημερώσεις»: αφήστε τις κενές στο staging

Η καρτέλα ζητά «Μυστικό ενημερώσεων» από το Kaiki, και δίνει μια διεύθυνση (/wp-json/kaiki/v1/webhook) για να την καλεί το Kaiki. Στον σημερινό κώδικα οι δύο πλευρές δεν ταιριάζουν: το πρόσθετο διαβάζει X-Kaiki-Signature με σκέτο hex, ενώ το Kaiki στέλνει Kaiki-Signature: v1=…· και το Kaiki στέλνει μόνο γεγονότα κρατήσεων (επιβεβαίωση, ακύρωση, αναχώρηση, στοιχεία επιβατών) — κανένα για αλλαγή καταλόγου. Επιπλέον τα webhooks είναι πακέτο Pro και οι δοκιμαστικές κρατήσεις δεν τα στέλνουν ποτέ. Χωρίς το μυστικό, ο κατάλογος στο WordPress ανανεώνεται στον χρόνο της προσωρινής μνήμης του προσθέτου — δουλεύει, απλώς όχι αμέσως. Για γρήγορες δοκιμές βάλτε την προσωρινή μνήμη στο ελάχιστο, 60 δευτερόλεπτα.

Αν το aegeancr.gr έχει δικά του φίλτρα

  • Πρόσθετο ασφαλείας ή Content-Security-Policy στο WordPress: να επιτρέπει script, fetch και εικόνες από το https://kaiki.testing.gr.
  • Cache σελίδων (WP Rocket, LiteSpeed κ.λπ.): καθαρίστε το μετά από κάθε αλλαγή ρυθμίσεων του προσθέτου, και εξαιρέστε τη σελίδα κράτησης από minify/συνδυασμό JavaScript.
  • Η φιλοξενία του aegeancr.gr πρέπει να επιτρέπει εξερχόμενο HTTPS προς το kaiki.testing.gr — ο έλεγχος σύνδεσης και οι σελίδες εκδρομών καλούν από τον server του WordPress, όχι από τον browser. Εκεί δεν μετρά ο Basic Auth: το /api/v1 είναι στις εξαιρέσεις.
