Kaiki on a phone, built from boxes

Captains and operators will mostly use Kaiki from a phone, so these mockups start there. The home page is version 3 (the day, by boat), turned into boxes you can tap with a thumb. Two ways to get around (A and B), each shown on a phone and a tablet, plus what lists like Κρατήσεις would look like. Example data, and nothing is built from these yet.

A

Menu button, and the menu opens as boxes

The phone keeps a menu button at the top. Tapping it opens the whole of Menu 1 as a grid of big boxes, so nothing is hidden in a long list. The home page opens with the next departure, then shortcut boxes, then one box per boat for today.

Lists

Every list becomes boxes on a phone

This applies to A and B alike. Κρατήσεις, Αναχωρήσεις, Προσφορές and the rest are tables today, and on a phone you scroll a table sideways to find the column you need. Below a tablet's width each row becomes a box. From tablet width up, the table stays.

Pick A or B

A or B decides how people get around on a phone. The home page (version 3, the day by boat) and the list boxes come with either one. Some possible answers:

  • A: menu button, menu as boxes.
  • B: bottom bar, with the captain's screen.
  • A with B's captain screen: the owner gets A, and crew accounts open straight to their boat.
