Πληρωμή (/c/): οι προτάσεις

  1. 1Η ίδια γραμματοσειρά με το site μεγάλη

    Η σελίδα πληρωμής ζητάει επίσης «Inter» χωρίς να το φορτώνει και πέφτει σε system-ui (Segoe UI στα Windows, San Francisco στο Mac): ο επισκέπτης βλέπει άλλη γραμματοσειρά από αυτήν που είχε η εκδρομή ένα κλικ πριν.

    system-ui → Inter, το ίδιο αρχείο με τις σελίδες του site
  2. 2Σύνδεσμος στο χρώμα της σελίδας, όχι στο μπλε του browser μεγάλη

    Το «Πλήρης πολιτική ακύρωσης» είναι #0000EE, το προεπιλεγμένο μπλε του browser.

    #0000EE → #1B5FD1 / 600, χωρίς υπογράμμιση
  3. 3Ετικέτες πεδίων: αντίθεση μεγάλη

    Οι ετικέτες μέσα στα πεδία είναι 55% μαύρο (3,8:1).

    rgba(15,32,43,.55) → #5F716E (5,1:1)
  4. 4Δύο γκρι, τα ίδια με του site μεσαία

    Εδώ υπάρχουν rgba(0,0,0,.6), rgba(15,32,43,.55) και .62. Στο site είναι #4A5D5A και #7B8D8A.

    τρία γκρι με διαφάνεια → #4A5D5A (δευτερεύον κείμενο) και #5F716E (ετικέτες)
  5. 5Κουμπί πληρωμής στο accent μεσαία

    Όλα τα γεμάτα κουμπιά του site είναι #1B5FD1· το «Πληρωμή» είναι σκούρο μπλε #123A5E, οπότε η τελευταία κίνηση δεν μοιάζει με τις προηγούμενες.

    #123A5E → #1B5FD1
  6. 6Μικρά κείμενα στην κλίμακα μεσαία

    Κωδικός κράτησης 11,52 / +0.09em, «Ακύρωση» 13,1 / 700 / +0.04em, «Σύνολο» της μπάρας στο κινητό 11,2, «Ενήλικας» 11,5.

    → 13 / 600 / +0.02em για όλα · h2 17,28 → 18 / 700 / #0E2D49 · h1 30,4 → 24→32 / 700
  7. 7Χωρίς κεφαλαία στον κωδικό έκπτωσης μικρή

    Το πεδίο κωδικού έχει text-transform: uppercase, που παραβιάζει τον κανόνα της σελίδας. Τον κωδικό τον κανονικοποιεί ο server.

    uppercase → none
